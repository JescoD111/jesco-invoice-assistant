JESCO 正式版 0.5.15

电商发票助手

从订单到发票，少一些重复输入。
适用于 FashionPO、PFS 与 Fatture in Cloud。

安装一次，以后直接更新

第一次使用，先安装篡改猴。已经装好？直接点蓝色按钮。

安装 / 更新助手 先安装篡改猴

Windows Chrome / Edge · 无需 GitHub 账号 · 无需复制代码

  1. 安装篡改猴，并按浏览器提示开启“允许用户脚本”。
  2. 点击“安装 / 更新助手”，在篡改猴确认页核对名称与版本后确认。
  3. 打开并登录业务平台，即可使用助手。更新后请结束当前任务再刷新页面。
已有用户：直接更新，不要先卸载旧脚本，也不要重复安装两份。订单池与国家映射保存在当前浏览器中。
点安装后只看到了代码，怎么办？

不要复制代码。先确认篡改猴已安装、已启用并允许用户脚本，再重新点击安装按钮。如果仍未弹出安装页，可打开篡改猴管理面板 → 实用工具 → 从 URL 安装，填入下面脚本链接的地址，再确认安装。

脚本直链（可右键复制链接地址）

以后怎样更新？

篡改猴会按本机更新设置检查正式版本；也可在篡改猴管理面板手动检查更新，或回到此页点击“安装 / 更新助手”。不是发布后立即强制更新；当前正在开票时，请先结束本次任务。

订单资料会上传到这里吗？

不会。这个页面只提供程序下载。助手在你的浏览器中处理数据，并与对应业务平台交互。GitHub 托管服务可能记录普通访问日志，但本安装页面不收集客户或订单。

首次用于其他公司账号

请先核对商品模板代码与发票模板配置是否一致。程序不能代替税务判断；客户税务设置及最终发票仍需人工审核。
